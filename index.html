Protocolo para acercarse a CELPIP 10+
  1. Haz un pack nuevo completo y deja avanzar el reloj aunque una pregunta siga dudosa.

  3. Compra un set oficial para calibrar: usa sus dos Reading como mediciones, no como material para memorizar.

Antes de empezar

Los bloques avanzan con su propio reloj. Cuando uno termina, no puedes volver. Si existe contenido no puntuado, no sabrás cuál es hasta finalizar el pack.

  1. Usa computadora o tablet en un lugar sin interrupciones.
  2. No uses diccionario, traducción ni ayuda.
  3. El examen real suministra papel: anota sólo números y palabras clave, nunca preguntas completas.
  4. Si dudas, decide y sigue; el reloj continúa si cambias de pestaña o recargas.
